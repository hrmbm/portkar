# Referensi sumber asli

`Code.gs-DISC-asli.txt` adalah lampiran asli pengguna untuk menjaga jejak sumber. Runtime Portal Karir memakai `assets/js/disc-engine.js`, yaitu port mesin perhitungan DISC ke JavaScript untuk frontend dan pencetakan.

Master formulir cetak runtime berada pada `templates/application-master.html` dan dipertahankan dengan atribut field yang sama agar seluruh isian lamaran tetap dapat dicetak.
